## 领域掌握度

掌握度取值：`陌生` / `接触过` / `想回炉`（熟悉但不扎实）/ `扎实`。
- `接触过`、`想回炉`：讲得好的 explainer / survey 会进入"温故"栏，而不是被降权。
- `扎实`：只推真正的新进展。

优先级取值示例：`最高` / `高` / `中高` / `中` / `低` / `极低` / `扩展`（只进入"意外"栏候选）。

| 领域 | 掌握度 | 优先级 | 说明 |
|---|---|---|---|
| （例）领域 A（可在括号里列出关键子主题） | 想回炉 | 高 | 为什么关注、目前的程度 |
| （例）领域 B | 陌生 | 中 | |
| （例）领域 C | 扎实 | 低 | 只看新进展 |

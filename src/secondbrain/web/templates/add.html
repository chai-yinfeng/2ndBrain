手动添加文章

把读过或想读的文章补录进来：归到虚拟信源 manual，不进 L1 / L2 / 分级 / 每日预算，只记录状态与反馈（反馈照常用于画像与 few-shot）。已存在的链接只更新状态与反馈。条目页上的深度速读、补前置照常可用（按需付费）。

每行一个，可批量。arXiv 链接取 HTML 或 PDF 正文；含 DOI 的链接（doi.org、ACM DL 等）先查 Semantic Scholar，取不到全文时只导入标题与摘要。

状态
已读时（选"准备读"时忽略）

留空 = 已读、无评价（只记录已读时间）。

仅"已读 + 有收获"可用；不勾选时会留在首页"待编进 wiki"里。每篇约 1 分钟，按 strong 模型计费。

抓取不到时的兜底（可选，仅单个链接，二选一）

付费墙、需要登录或拒绝机器访问的页面（如 ACM DL 返回 403）抓取失败、或只拿到摘要时使用。PDF ≤ 30MB，用现有的 PDF 提取。

后台逐个抓取与提取正文（每个链接几秒），不调用 LLM；单个失败不影响其他，失败时会给出具体原因。

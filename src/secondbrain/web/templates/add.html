添加材料

文章、论文、网页、PDF 和文本共用一个材料入口。默认加入你自己的稍后阅读清单；已在外部读过的内容可以直接登记并整理。持续更新的主页可去信源关注。

URL / PDF / 文本

每行一个，可批量。arXiv 链接取 HTML 或 PDF 正文；含 DOI 的链接（doi.org、ACM DL 等）先查 Semantic Scholar，取不到全文时只导入标题与摘要。

状态
外部学习记录（登记已读时使用；仅单份材料）
独立材料或单个链接的补充正文（二选一）

不填 URL 也可独立导入。PDF ≤30MB，保留原文件；只有摘要的内容会明确标注，不作为全文。

加入清单本身不调用 LLM。登记已读才增量整理；正文与学习记录都没变化时复用已有结果。失败保留材料和已读记录。

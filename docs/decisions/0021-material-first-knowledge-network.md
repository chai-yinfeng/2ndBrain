# 0021 — 以材料与个人知识网络为主线

- 状态：已接受（架构方向；具体交互与 LLM 实现未定）
- 日期：2026-11-16
- 实施：Roadmap M13–M15，尚未开始

## 背景

M0–M12 以订阅采集、过滤、每日预算推荐为主线，阅读后通过“有收获”反馈编入 wiki。用户当前已有大量待学习的论文与博客，主动导入、整理已读内容和连接知识比发现新信源更重要。论文名检索和自动获取材料应由系统承担，不要求用户先手工找到会议或平台链接。

本次只确定核心架构与可观察的验收结果，不提前指定 Agent 框架、搜索服务、prompt、思考强度或数据库字段。实现机制应服从学习知识库，而不是保留旧推荐流程的强制依赖。

## 决策

1. 主流程改为主动输入 → 统一材料库 → 阅读与知识整理 → Markdown wiki → 个人知识网络。订阅是辅助输入，时间预算推荐是可选消费者，不删除其已有能力。
2. 材料身份与采集来源分离。PDF、URL、文本、论文名解析结果和订阅共用导入、去重、补全与来源记录；支持无 URL 的本地 PDF。论文名检索只负责解析输入和寻找材料，不另建材料库。
3. 阅读状态、机器处理状态和推荐状态分离。任意材料可显式整理入 wiki，不要求先运行 L2、产生 digest 或标记“有收获”。已导入、已整理均不代表用户已掌握；原文、机器内容与个人笔记可区分。
4. SQLite 保存材料与流程记录；知识页面和链接以 Obsidian 兼容 Markdown 为事实来源。图谱、反向链接与索引从文件派生、可重建，支持外部编辑后重新索引，不增加图数据库或独立可编辑图存储。
5. 图谱提供全局概览与围绕当前节点的局部展开；页面承载完整知识内容、关联、反向链接及原文来源。图谱不是只能观看的图片，也不替代阅读页面。具体布局、预览面板与点击方式留给交互设计。
6. 普通 wikilink 表示关联，不能直接解释为引用、因果或前置关系。关系说明和依据保存在页面中，机器推断可辨认；暂不固定有类型、有方向的边模型。
7. Web 与 Obsidian 使用同一 vault，保证文件、链接和内容语义一致，不要求视觉布局相同。渲染和交互必须通过真实浏览器及 Obsidian 验收；无法运行的一端明确记为未验证。
8. 迁移保留现有材料、反馈、用户笔记与 wiki 链接；在旧库副本验证，不重置个人数据。CLI/Web 统一切换到新接口，不添加平行导入流程或长期兼容壳。

## 与现有实现的冲突及处理

| 现有机制 | 新边界 / 迁移要求 |
|---|---|
| `items` 依赖 sources，手动内容挂在 `manual` 虚拟信源 | 材料身份独立，来源是可多值的记录；内部 schema 在 M13 确定 |
| PDF 是 `sb add <url> --pdf` 的兜底 | 文件成为独立输入，URL 与论文名是其他输入 |
| `items.status` 描述过滤流程，阅读状态由反馈派生 | 分离阅读、处理与推荐状态，保留反馈历史 |
| `pending_items` 仅选择 gained；wiki 输入依赖 L2，长文只用要点 | 独立知识整理入口，从材料组织必要内容，不强制先走推荐 |
| `related_pages` 主要靠名称提及，图谱由现有 wikilink 生成 | 提升相关页面发现与内容关联，但不预先指定 embedding 或关系抽取算法 |
| 图谱只有全局视图、类型/掌握度筛选、点击跳转；边无方向，raw 不入图 | 增加局部浏览与反向链接，材料页能进入网络；原文文件不必作为独立图节点 |
| 首页以 digest 与每日预算为核心 | 材料与知识网络成为主入口，推荐保留为辅助视图 |
| wiki 页面存在与复习/已知知识信号相连 | 未读材料可生成页面，不能据此自动提升掌握度或认定为用户已知 |

此表是行为边界，不是未经代码调查的函数改名或字段删除清单。旧 ADR 的已实现行为保留作为历史；涉及主线、入库门槛与掌握度含义时，以本 ADR 为新目标。

## 仍待设计的细节

- 节点展开的具体手势、局部图布局、预览与详情的组织方式。
- 材料页与既有 paper/entity/concept 页面如何迁移并保持稳定链接。
- 论文候选检索/消歧、正文定位、版本匹配和失败展示的具体策略。
- LLM 如何总结长文、发现关联、提供来源依据；prompt、模型与思考强度。
- 是否需要有类型/方向关系，以及何时值得加入语义索引。

以上细节不视为已确定。实施时可选择满足架构与验收的保守方案；若需要改变已接受边界，先讨论再更新 ADR。

## 后果

- 正面：没有订阅、推荐或读后反馈也能使用核心系统；论文与博客可以围绕共享概念连接，知识仍可直接在 Obsidian 中使用。
- 成本：需要迁移状态与来源语义、解耦 wiki 编译入口、调整首页和图谱，而不只是新增一个“智能导入”按钮。
- 风险：自动生成容易制造无依据链接、覆盖笔记或把接触当掌握；通过来源可追溯、个人内容保护和状态分离约束。
- 范围：M13 统一材料与整理，M14 知识网络与展示，M15 论文名导入。订阅增强、图数据库、复杂关系本体和模型调参实验不进入本轮。

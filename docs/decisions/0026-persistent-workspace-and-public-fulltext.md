# 0026 — 持久工作区与通用公开全文获取

- 状态：已接受（用户授权迁移位置、专用采集清退与全文流程实施；验收见 progress）
- 日期：2026-11-18

## 背景

隔离验收目录后来承载了真实使用记录，不能继续依赖操作系统临时目录。Qwen Research、HF Papers 专用接口又扩大了站点规则维护面，用户明确要求清退。论文元数据查询成功不代表获得全文，知乎403也不能直接推导成必须登录；导入结果必须说明实际取得的内容。

## 决策

1. 用户明确选择 `~/Library/Application Support/SecondBrain` 作为个人持久根目录，包含 data、config 与运行时env文件。整套迁移材料库、任务库、原件、Markdown/wiki、笔记、画像与配置；停服后复制，文件摘要与SQLite完整性校验通过才切换。不混入仓库原有data，不重新导入、不调用模型、不改launchd或原项目.env。迁移前恢复副本放在持久根目录的 migration-backups 中，有明确恢复位置，不散落临时目录。
2. RSS、sitemap、HTML index 保留通用发现；arXiv、YouTube 保留平台级支持。彻底移除 `hf_papers` 与 `qwen_research` 的采集枚举、注册、站点专用实现和匹配，不留运行时旧类型别名。存量两类关注原位改为现有手动主页表示（rss + needs_scraper=true、url/homepage为人工主页），保持ID、名称、标签、信任度及其他人工属性；历史材料与来源记录不删改。通用规则以后仍可发现这些域名的公开内容，不硬禁站点。此决定更新ADR 0025的保留专用规则边界。
3. 分开“确认材料身份”“查找公开全文”“提取内容”。已有摘要不终止全文查找；继续尝试已知开放地址及落地页标准 citation_pdf_url 等泛用入口。URL、论文名和DOI复用统一材料服务，不为单篇论文或实验室写专用爬虫，不新增通用搜索服务或模型检索费用。
4. 每次获取保存完整度、提取方式、实际内容来源、实际版本以及有界尝试/错误信息。实际来源必须对应选中的正文或摘要，不取最后一个失败请求地址。正文缺失、仅摘要、部分正文与全文明确区分；未知版本不猜测，摘要不冒充全文。身份核对、较完整材料升级、原件保留及用户笔记保护沿用既有规则。
5. HTTP 403只表示本次请求被拒绝，原因可能是访问策略、风控或请求环境；不能据此断言必须提供Cookie。当前不自动借用浏览器登录态、不收集账号密码、不绕验证码或付费墙，也不重复刷被拒绝的地址。保留手动浏览、显式粘贴正文或上传PDF的现有入口。

## 边界

本轮不增加网页截图、浏览器扩展、OCR/视觉解析或跨站搜索API，也不自动重跑用户已有论文或付费知识整理。恢复副本是明确保留的数据保护内容，不作为开发临时夹具清除。M14原生Obsidian验收缺口保持；不push或创建PR。

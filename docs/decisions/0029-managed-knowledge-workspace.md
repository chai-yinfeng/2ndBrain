# 0029 — 可管理的知识工作区与按需单页重整

- 状态：已接受；具体验收状态见 `docs/progress.md`
- 日期：2026-11-18
- 关联：ADR 0021、0022、0027、0028

## 背景

统一材料身份后，知识目录仍按旧paper/material类型分组，造成论文集中在Materials、Papers空置。用户主要在外部阅读，按需检索概念，不需要维护掌握度或间隔复习。重复的“机器整理未经核对”和内部数字编号增加干扰，现有追加式整理也不能替代带临时语境的主动修订。各个新增列表必须同时具备移出、删除或可恢复回收能力。

## 决策

1. 后台材料身份仍统一，知识资料按论文、文章与网页、视频、其他资料呈现，概念和实体保留。分类复用明确书目/来源事实，允许人工覆盖；不凭PDF格式认定论文。旧paper页和material路径保持，不创建副本；分类迁移不调用模型、不重写个人正文，空类不占目录。
2. 退出掌握度、复习评分、间隔调度及其推荐/上下文作用。新页不生成相应字段，旧字段不再必填或参与行为；原用户文件中的旧信息可以留存，不以移除功能为由删除个人文字。领域画像改为兴趣与优先级，相关知识只是内容参考，不代表用户掌握。
3. 正常页面显示知识正文、语义类别和来源标题，不显示数据库编号或重复的机器免责声明。内部身份、生成归属和稳定链接继续保留。仅对原文缺失、仅摘要、来源变化等实质证据缺口提示；不能删掉限制后冒称全文可靠。
4. 所有集合有对应管理动作：阅读清单单个/批量移出不删材料；材料复用隐藏/回收/恢复；已结束任务可单个/批量/全部删除，运行和待选择保护，业务材料及用量独立保留；知识页单个/批量回收恢复，确认时展示反链影响；信源明确删除配置并保留历史。新建的重整会话也可删除，历史版本可显式清空，不能再增加只能增长的列表。
5. 知识回收使用元数据，不移动或物理删除正文。正式目录、图谱、相关上下文和自动整理排除回收页，后续同步不得自动复活或生成同身份替身。链接影响可检查，个人笔记/原件与知识页管理分离。多文件操作遇冲突要明确已处理和未处理范围，不用失败提示掩盖部分结果。
6. 单页重整使用临时上下文会话：当前完整页面、实际已保存来源和有界相关知识进入模型，生成草稿可继续对话；用户明确采用才替换可确认的AI整理区，而不是无限追加。无法确认归属的人工正文、个人笔记、来源和人工关系保留。采用前核对版本，保存历史，支持回退。临时语境只属于会话，不改画像或长期个人笔记；会话恢复不自动重放付费调用。
7. 重整沿用现有模型后端、价格、用量与费用约束，无新Agent框架或依赖。原文和相关上下文有界提供并标识截断/完整性，不能把处理窗口误称全文。只修改当前知识页，不自动改全库或创造无依据节点。
8. 用户显式提供正文/PDF并保留原URL时，原URL只作来源引用，不再请求被拒绝网页；仍走统一去重、补全和原件保存。知乎403只证明该请求被拒绝，不推断必须Cookie，不刷请求、不绕登录或验证码。
9. 视觉保留左侧导航、紧凑列表和亮/暗/跟随系统；只参考TasteSkill的排版与一致性方法，不安装全局skill、不照搬营销页hero、大留白或动效，不因此迁React。

## 图谱边界

真实关系来自Markdown wikilink，现有concentric位置按连接度排列，圆形不表示语义距离。内容相似度、关系边和视觉布局是不同机制。语义聚类、embedding及新布局仍属讨论，不将相似性伪装成有证据的关系，本轮不引入相应依赖。

## 代价与迁移

导出API、模型字段、提示词、CLI/Web及消费者测试需要一起清退，不能仅藏掉复习按钮。稳定路径与原数据保留，不重排数字ID。个人工作区停服备份后才做明确的分类/派生目录迁移；开发与验证在临时目录，真实批量删除和付费重整不自动执行。

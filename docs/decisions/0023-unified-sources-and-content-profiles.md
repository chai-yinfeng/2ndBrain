# 0023 — 统一来源适配与基于内容的来源分类

- 状态：已接受（用户授权修复来源、保留已关注列表，并补齐领域能力）
- 日期：2026-11-17

## 背景

主页发现此前独立猜测 RSS、HTML 路径与 sitemap，没有复用目录中的专用适配。HF Papers 因此没有走公开 API，DeepMind 没有走已配置 RSS。目录添加与手动输入同一主页得到不同能力。获取方式、人工标签和内容领域也缺少清楚区分。

## 决策

1. 主页发现、配置预览、CLI/Web 共用已有 FETCHERS。先匹配关注配置，再匹配完整参考规则，再做通用发现；已关注适配失败时，在同一请求预算内尝试匹配的不同参考适配。只有验证成功或合法空结果才提出采集修复，全部失败保留配置与诊断，不退化成假成功的书签。
2. 来源匹配保留栏目路径、查询和显式规则，不仅按域名合并；不盲目认定 www、HTTP/HTTPS 等价，跳转须实际验证。显示目录隐藏不影响底层适配规则。
3. 所有发现/预览保持公网逐跳检查和有界请求。sitemap index 发现与实际采集共用展开逻辑：深度2、最多6文档、500候选，同源；共享发现预算最多8请求、每请求3跳、1MB，预览最多50条。不登录、不执行页面脚本、不绕过付费墙。
4. SourceConfig 增加可选显示名称 name，ID与名称分开。原位编辑保留未修改配置、顺序和注释；更改ID必须同步实际数据库外键及来源元数据，文件/数据库失败补偿恢复。修复仅改变已验证采集字段及缺失名称，不覆盖人工标签、trust、role、启停和材料。
5. 参考目录支持移除、清空和显式恢复，仅记当前工作空间的显示偏好；不删除关注、材料或内置识别规则。默认来源摘要为紧凑行，设置、分析依据和统计按需展开。
6. 免费展示现有目录标签和已保存文章分析主题，注明来源，不冒充新推断。需要更细分类时由用户显式分析：至多10份标题/摘要及既有分析作为证据，cheap模型输出领域、内容性质、摘要和置信度；证据链接由程序产生，不让模型伪造。
7. 分类与人工tags分开保存；不触发推荐、正文抓取、材料导入或阅读状态变化。相同输入与提示词复用缓存，命中不要求密钥；force显式重做。沿用费用上限，未知价格拒绝预调用，SOURCE阶段保存用量/错误，失败保留旧结果。不在来源修复或页面打开时自动批量计费。
8. schema v13仅追加 source_analyses 与 source_catalog_hidden；不重建/清空用户来源及材料。

## 取舍

不保证任意动态网站都可自动采集；空结果、网络失败、拒绝地址与手动浏览必须分开。来源领域只能代表有限样本，不等同于读完网站或理解全文；自动分类不升级知识掌握度。首次真实模型分类质量由用户显式触发检验，离线fake验收不冒充真实质量。

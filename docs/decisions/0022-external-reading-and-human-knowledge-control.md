# 0022 — 外部阅读登记与人工知识连接约束

- 状态：已接受（用户明确授权业务语义；视觉重设计不在本次范围）
- 日期：2026-11-16

## 背景

用户主要在原站、ChatGPT 等外部环境阅读与讨论。本应用的阅读列表是用户自己维护的稍后清单，不承担主要阅读器或自动推荐推送的职责。信源是长期关注的信息产生地；登记阅读后由 AI 增量整理知识，人工只在需要时介入关系和解释。

## 决策

1. 主入口按信源、阅读列表、知识库组织，设置与旧推荐作为辅助。沿用现有 HTML/CSS/HTMX，不在本次引入 shadcn 或 React 重写。
2. 信源配置缺失时关注列表为空；example 只是参考目录。显式关注才写正式配置，不在首次保存时自动关注全部示例；已有正式文件按条目编辑，保留其他内容和注释。主页发现优先现有 RSS/Atom、HTML 列表或 sitemap，无法枚举时诚实保存为手动浏览主页，不伪造更新。
3. `reading_list` 独立保存用户选择；关注、预览、采集和普通材料落库不自动入队。迁移仅接收当前 later 记录；反馈不再是清单事实来源。通用添加和论文名导入面向用户时默认加入清单，材料仍只有一个身份。
4. 登记已读是明确用户操作，不要求 gained 或评分。可附外部学习笔记及讨论 URL；URL 仅保存引用，不能声称已读取私有对话。无公开正文时允许显式保存网页引用，再依据用户提供的笔记整理；来源仍标 missing，笔记不冒充全文。
5. 登记后移出稍后清单，保留阅读事实与笔记，增量编译相关知识页。正文与笔记输入 hash 未变时复用已编译结果，不重复调用模型；缓存命中不要求 API key。正文或笔记变化、或用户显式 force 才重新处理。预算/模型失败不回滚已读，不删除材料，并提供待整理与重试入口。
6. 新生成页面区分 recorded 与 draft；未登记阅读的机器草稿不进入默认知识库图谱/目录。历史未标记页面作为 legacy 保留，不倒推用户已经读过。登记阅读或 AI 生成概念都不自动提升掌握度。
7. 人工 pin/block/reset 及关系依据保存在 Markdown frontmatter/人工归属小节，canonical vault 路径作为目标身份。固定关联保留普通 wikilink；禁止是双向约束，图谱/反链与机器写入共同执行，不仅依赖 prompt。解除约束允许今后自动维护，不自动恢复被禁止的旧机器连接。个人正文与笔记不被机器覆盖。
8. 复用现有分块与相关页面检索，不每次重写整个知识库。保持 `run.max_cost_usd`、用量与错误记录；人工改连接、关注预览和单纯加入清单不调用 LLM。

## 取舍

- 当前先提供可解释、可执行的固定/禁止/说明，不引入关系本体或图数据库。关系线仍是关联，不代表因果或前置知识。
- 手动浏览信源是完整的来源入口，但不承诺登录页、动态账号或任意网站都能自动列举更新。
- 历史知识保留，不通过猜测批量重置或伪造阅读状态。Obsidian 不识别应用自定义的 block 元数据；本轮以 Web 图谱和代码约束为准，不宣称已完成原生 Obsidian 跨端关系一致性验收。
- UI 样式和更大规模的信息架构改进待用户看本轮业务结果后另行讨论，不以本次功能实现代替视觉设计。

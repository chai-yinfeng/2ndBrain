# 0025 — 主动输入优先与可找回的导入任务

- 状态：已接受（用户确认本轮实施；验收结果见 progress）
- 日期：2026-11-17

## 背景

订阅只是主动学习的辅助入口。迁移时期的临时参考目录不再需要；为单个网站持续增加专用采集器会扩大维护面。Web 导入的后台线程虽不因切页停止，但进度入口与论文候选结果不能可靠找回，完成日志又长期挤占表单和信源列表。

## 决策

1. 删除临时参考目录的 Web/CLI 产品入口和隐藏/恢复操作，只允许用户主动输入主页来关注。保留当前所有关注、材料、笔记和既有采集规则；不为清退展示功能而删除历史数据库记录或重写个人配置。
2. 泛用网站发现沿用 RSS、HTML 列表与 sitemap。arXiv、Hugging Face Papers、YouTube 保留平台级入口。不再新增 Qwen Research 一类单站专用适配；现有 `qwen_research` 规则保留以避免破坏已关注配置，不承诺跟进站点接口变更。无法可靠自动枚举时明确降为用户确认的手动浏览入口，不伪造自动采集能力。页面正文提取与栏目文章枚举仍是不同能力。
3. 链接、论文、文件、文本只在材料获取路径上有区别，后续共用稍后阅读、仅存档、外部已读登记及知识整理语义。论文需要选择候选时保留状态、学习笔记和讨论引用；不得因任务线程结束而把“等待选择”显示成导入成功。
4. 导入任务记录与表单分离。运行进度、结果、错误与论文待选入口可重新打开；服务重启后未完成线程标记中断，不自动重放网络请求或付费整理。历史论文候选从已有持久记录恢复，不重新检索或替用户自动选择。
5. 检查采集配置只读验证；修复只保存已验证的采集字段，不覆盖人工属性、不取消关注、不调用模型。检查、修复与详细日志在可关闭窗口/折叠区域呈现，关闭不取消任务，也不把长结果回填到信源列表。
6. 信源列表和封面卡片是同一批关注的两种视图，共用排序与设置入口，偏好仅保存在浏览器。封面显式按需更新，优先网页封面、其次站点图标、最后名称首字母；只从安全有界获取的本地缓存展示，不调用模型、不引入外部图片代理。封面失败不改变采集能力。

## 后果与边界

减少推荐目录和单站适配维护，把可靠性投入统一材料、候选确认与任务可见性。封面不是截图或语义理解，站点没有公开图片时使用回退图标。任务持久化不等于跨进程自动续跑；中断后由用户明确重试，材料去重和已登记事实沿用现有服务。

封面复用既有 Reader 的逐跳公网地址/DNS 预检查和解压后下载预算，拒绝 SVG/HTML 与不匹配的栅格类型，不在页面中直接嵌入远程图片 URL。现有网络层未将已验证 DNS 结果绑定到连接 IP，因此不声称抵御 DNS rebinding；本轮不扩展到通用 transport 重构。

本决策更新 ADR 0023 的临时参考目录方向及 ADR 0024 的单站扩展方向，不撤销已经保存的来源。M14 的原生 Obsidian 验收缺口保持，不因本轮 UI/导入改进标记完成。不 push、不创建 PR、不修改真实数据、个人配置或 launchd。

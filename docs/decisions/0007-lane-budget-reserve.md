# 0007 — 为温故与意外栏预留时间预算

- 状态：已接受
- 日期：2026-11-04

## 背景

ADR 0004 以每日时间预算为主约束，ADR 0006 规定预算按 must_read → refresher → serendipity → worth_it 的顺序分配。M2 的真实运行中，1–2 篇长文（40–90 分钟）就占满了 105 分钟预算，温故与意外栏经常为空。而这两栏正是 ADR 0003（"熟悉 ≠ 掌握"）和"意外名额"原则要保护的内容。

## 决策

- settings 新增 `lane_budget_reserve`，默认 `refresher: 15`、`serendipity: 10`（分钟）。
- 分级开始时，对每个设置了保留额度的 lane：若当天还有名额且存在合格候选，就保留该额度；否则不保留。
- 其他 lane（must_read、worth_it，以及放进这些 lane 的顺延条目）的可用预算 = 剩余预算 − 仍在保留中的额度，因此 must_read 不会占用保留额度。
- 被保留的 lane 自己可以使用自己的保留额度和公共剩余预算。
- 该 lane 分配结束后，未用完的保留额度释放回总预算，供后面的 lane（如 worth_it）使用。
- 设为 0 即关闭预留。

## 后果

- 正面：只要当天有合格的温故 / 意外候选，它们就能稳定出现；没有候选时不浪费预算。
- 负面：必读可用的预算默认少 25 分钟，长文更容易被标为深读并顺延；保留额度小于单条候选的 est_minutes 时，该候选仍需占用公共预算，可能依旧放不下。
